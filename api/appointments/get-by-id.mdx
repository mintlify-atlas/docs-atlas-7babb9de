---

## Overview

This endpoint retrieves a single appointment by its unique ID. Returns the complete appointment record including all fields.

## Authentication

Requires a valid JWT token in the request headers.

```bash
Authorization: Bearer <jwt_token>
```

## Path Parameters

<ParamField path="id" type="number" required>
  The unique identifier of the appointment to retrieve.
  
  **Example:** `123`
</ParamField>

## Response

Returns a single appointment object:

<ResponseField name="appointment" type="object">
  <Expandable title="Appointment Details">
    <ResponseField name="id" type="number">
      Unique appointment identifier
    </ResponseField>
    
    <ResponseField name="patientID" type="number">
      ID of the patient this appointment belongs to
    </ResponseField>
    
    <ResponseField name="professionalID" type="number">
      ID of the professional assigned to this appointment
    </ResponseField>
    
    <ResponseField name="date" type="string">
      Appointment date in ISO 8601 format (YYYY-MM-DD)
      
      **Example:** `"2026-03-15"`
    </ResponseField>
    
    <ResponseField name="time" type="string">
      Appointment time in 24-hour format (HH:mm:ss)
      
      **Example:** `"10:30:00"`
    </ResponseField>
    
    <ResponseField name="description" type="string">
      Reason for the appointment or notes about what will be addressed
      
      **Example:** `"Control mensual de diabetes"`
    </ResponseField>
    
    <ResponseField name="state" type="string">
      Current state of the appointment. One of:
      - `Pendiente` - Scheduled and waiting
      - `Atendido` - Patient was seen and appointment completed
      - `Cancelado` - Appointment was cancelled
      - `Ausente` - Patient did not show up
    </ResponseField>
    
    <ResponseField name="createdAt" type="string">
      Timestamp when the appointment was created
    </ResponseField>
    
    <ResponseField name="updatedAt" type="string">
      Timestamp when the appointment was last updated
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

### Get Appointment by ID

<CodeGroup>
```bash cURL
curl -X GET "https://api.clinicavitalis.com/appointments/123" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

```javascript JavaScript
const appointmentId = 123;

const response = await fetch(
  `https://api.clinicavitalis.com/appointments/${appointmentId}`,
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
    }
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

appointment_id = 123

headers = {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
}

response = requests.get(
    f'https://api.clinicavitalis.com/appointments/{appointment_id}',
    headers=headers
)

data = response.json()
print(data)
```
</CodeGroup>

## Error Responses

### 404 Not Found

Returned when the appointment with the specified ID does not exist:

```json
{
  "msg": "El turno no está cargado en el sistema"
}
```

### 401 Unauthorized

Returned when the JWT token is missing or invalid:

```json
{
  "msg": "Token inválido o no proporcionado"
}
```

### 500 Server Error

Returned when a server error occurs:

```json
{
  "msg": "Error del servidor"
}
```

## Use Cases

- **Appointment Details View**: Display full information about a specific appointment
- **Update Preparation**: Fetch current appointment data before allowing modifications
- **Verification**: Confirm appointment details before performing operations
- **History Review**: View past appointment information for patient records
