# Welcome to Clínica Vitalis

**Clínica Vitalis** is a comprehensive administrative platform designed to optimize internal workflow in healthcare facilities. This platform addresses the critical need to manage medical staff and patient admissions, with a focus on **efficient resource allocation**.

## What is Clínica Vitalis?

Clínica Vitalis is a full-stack Hospital Staff Manager that provides healthcare administrators with the tools they need to:

- Manage medical professionals and their specialties
- Handle patient registrations and records
- Schedule and track appointments efficiently
- Coordinate work schedules for medical staff
- Manage insurance providers (obras sociales)
- Apply intelligent filtering across all resources

The platform was built as a robust **MVP (Minimum Viable Product)** using the MERN stack with TypeScript, demonstrating professional handling of relational databases and modern web architecture.

## Technology Stack

Clínica Vitalis is built with modern technologies following best practices:

### Frontend
- **React 19** with **TypeScript** for type-safe UI development
- **Vite** with SWC for lightning-fast builds
- **Redux Toolkit** for predictable state management
- **Material-UI** for professional, accessible components
- **React Router** for seamless navigation

### Backend
- **Node.js** with **Express** for robust API services
- **TypeScript** for type safety across the entire stack
- **Sequelize ORM** for elegant database modeling
- **SQLite** for reliable data persistence
- **JWT** for secure authentication
- **bcryptjs** for password hashing

### Key Features
- Role-based access control (Admin/User)
- RESTful API architecture
- Comprehensive validation with express-validator
- Relational data modeling with proper associations
- CORS enabled for secure cross-origin requests

<Note>
Clínica Vitalis demonstrates enterprise-level architecture patterns while maintaining simplicity and ease of deployment.
</Note>
